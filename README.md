# Coastal Seven - Luxury E-Commerce Platform (Final Project)

A complete, production-ready full-stack luxury e-commerce platform built with FastAPI, PostgreSQL/SQLite, Celery, Redis, React 19, Vite, and Zustand.

## Architecture

- **Backend (Render)**: FastAPI Web Service with asynchronous order processing, JWT authentication, WebSocket live order tracking and support chat, and Celery background task workers.
- **Frontend (Vercel)**: React + Vite modern luxury storefront, responsive mobile design, state management with Zustand and React Query.
